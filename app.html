Database untuk PC Lain — Backup & Restore

Database tersimpan di localStorage (per browser, per akun) + file offline. Untuk pindah PC, pakai Backup.

Manual (tanpa backup): Copy folder C:\shopee-recon\data ke PC lain di lokasi sama, atau copy file backup .json via Flashdisk/Google Drive.
- File PC: data/hpp.json, data/pelanggan.json, data/months/*.xlsx
- Browser: Backup .json ini sudah termasuk semua bulan + HPP + pelanggan + beban manual per akun — cukup Restore di PC lain.

Laporan Penghasilan - Beban (Laba Bersih)

Subtotal Pesanan = Harga Produk (sebelum diskon/beban). Penghasilan = Total Penghasilan (kolom Shopee). Laba Bersih = Penghasilan - HPP - Beban Manual. Ongkir Bersih = Ongkos Kirim ke Jasa - Gratis Ongkir dari Shopee (net).

💰 Beban di Luar Excel Shopee (Mis: Biaya Iklan Manual / Ads)
